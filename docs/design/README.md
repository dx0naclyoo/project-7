# Макет веб-клиента

Живая версия: https://claude.ai/artifact/2eDsT5Twmrgwr9o8b3pubg

Здесь лежит копия файлов макета, по одному файлу на артборд. `canvas.json` хранит их
расположение на холсте. Сами по себе файлы в браузере не откроются: для них нужен холст.

## Отдых между подходами

1. Идёт подход: на экране упражнение, номер подхода и кнопка «Стоп».
2. Закончил подход и нажал «Стоп»: пошёл отсчёт установленного времени отдыха.
   Время можно поменять на 15 секунд в обе стороны или пропустить отдых.
3. Время вышло: начинается следующий подход. Сигнала пока нет.

Время отдыха задаётся в профиле. В макете 1:30 и 48 часов восстановления это примеры.

В `web/` этого пока нет. В API тоже нет ни времени отдыха, ни времени восстановления.
